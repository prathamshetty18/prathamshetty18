**Tech:** FastAPI · ChromaDB · Gemini API · React

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/prathamshetty18/VH26-TEAM_HARMONY)

### 🍽️ Token-Diet — LLM Token Optimization
A semantic relevance pipeline designed to reduce unnecessary prompt content through chunking, embeddings, relevance scoring, and deduplication before sending prompts to an LLM.

**Tech:** Python · Embeddings · Semantic Search

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/srjn18/DevJams-26-Team_Harmony)
